### 📄 **الخطوة 2: نسخ الأكواد (انسخ والصق في كل ملف)**

#### **الملف الأول: `db.php`** (العقل وقاعدة البيانات)
*هذا الملف سينشئ قاعدة البيانات والجداول والبيانات التجريبية (بما فيها روابط فودافون وأورنج) تلقائياً عند أول تشغيل.*

```php
<?php
// db.php - إعداد قاعدة البيانات المحلية (SQLite)
$dbPath = __DIR__ . '/database.sqlite';
$pdo = new PDO('sqlite:' . $dbPath);
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec('PRAGMA foreign_keys = ON;');

// إنشاء الجداول إذا لم تكن موجودة
$pdo->exec("
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    role TEXT DEFAULT 'user',
    status TEXT DEFAULT 'active'
);

CREATE TABLE IF NOT EXISTS companies (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    name_ar TEXT NOT NULL,
    is_active INTEGER DEFAULT 1
);

CREATE TABLE IF NOT EXISTS servers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    company_id INTEGER,
    display_name TEXT NOT NULL,
    host TEXT NOT NULL,
    port INTEGER DEFAULT 443,
    sni_hostname TEXT NOT NULL,
    payload TEXT NOT NULL,
    FOREIGN KEY (company_id) REFERENCES companies(id)
);

CREATE TABLE IF NOT EXISTS spoof_urls (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    company_id INTEGER,
    url TEXT NOT NULL,
    description TEXT,
    is_active INTEGER DEFAULT 1,
    FOREIGN KEY (company_id) REFERENCES companies(id)
);

CREATE TABLE IF NOT EXISTS sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    token TEXT UNIQUE NOT NULL,
    expires_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
");

// إدخال البيانات الافتراضية (مرة واحدة فقط)
$stmt = $pdo->query("SELECT COUNT(*) FROM users");
if ($stmt->fetchColumn() == 0) {
    // 1. الأدمن
    $pdo->exec("INSERT INTO users (username, password, role) VALUES ('admin', '" . password_hash('password', PASSWORD_DEFAULT) . "', 'admin')");
    
    // 2. الشركات
    $pdo->exec("INSERT INTO companies (name, name_ar) VALUES ('Vodafone', 'فودافون'), ('Orange', 'اورنج'), ('Etisalat', 'اتصالات'), ('WE', 'وي')");
    
    // 3. سيرفرات تجريبية
    $pdo->exec("INSERT INTO servers (company_id, display_name, host, sni_hostname, payload) VALUES 
    (1, 'فودافون 1', 'vpn1.btc.com', 'web.vodafone.com.eg', 'GET / HTTP/1.1[crlf]Host: web.vodafone.com.eg[crlf][crlf]'),
    (2, 'اورنج 1', 'vpn2.btc.com', 'my.orange.eg', 'GET / HTTP/1.1[crlf]Host: my.orange.eg[crlf][crlf]')");

    // 4. روابط التمويه (Spoof URLs)
    $pdo->exec("INSERT INTO spoof_urls (company_id, url, description) VALUES 
    (1, 'web.vodafone.com.eg/portal/homeUtilitiesPromo', 'فودافون - الصفحة الرئيسية'),
    (1, 'web.vodafone.com.eg/spa/bf/dlm', 'فودافون - DLM'),
    (1, 'eshop.vodafone.com.eg/ar/profile', 'فودافون شوب - الملف الشخصي'),
    (2, 'eshop.orange.eg/ar/preorder', 'اورنج شوب - الطلب المسبق'),
    (2, 'www.orange.eg/ar/MyAccount/Pages/pay.aspx', 'اورنج - الدفع'),
    (3, 'my.etisalat.eg', 'اتصالات - حسابي'),
    (4, 'my.te.eg', 'وي - حسابي')");
}
?>
```

#### **الملف الثاني: `api.php`** (واجهة البرمجة للتطبيق)
*هذا الملف يستقبل طلبات تطبيق الأندرويد ويرد عليها.*

```php
<?php
// api.php - واجهة برمجة التطبيقات
header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type, Authorization');

require 'db.php';

$action = $_GET['action'] ?? '';
$input = json_decode(file_get_contents('php://input'), true) ?: [];

// 1. تسجيل الدخول
if ($action === 'login') {
    $username = $input['username'] ?? '';
    $password = $input['password'] ?? '';
    
    $stmt = $pdo->prepare("SELECT * FROM users WHERE username = ? AND status = 'active'");
    $stmt->execute([$username]);
    $user = $stmt->fetch(PDO::FETCH_ASSOC);
    
    if ($user && password_verify($password, $user['password'])) {
        $token = bin2hex(random_bytes(16));
        $expires = date('Y-m-d H:i:s', strtotime('+7 days'));
        $pdo->prepare("INSERT INTO sessions (user_id, token, expires_at) VALUES (?, ?, ?)")
            ->execute([$user['id'], $token, $expires]);
            
        echo json_encode([
            'success' => true,
            'message' => 'تم تسجيل الدخول بنجاح',
            'data' => ['token' => $token, 'user' => ['username' => $user['username'], 'role' => $user['role']]]
        ]);
    } else {
        echo json_encode(['success' => false, 'message' => 'اسم المستخدم أو كلمة المرور غير صحيحة']);
    }
    exit;
}

// 2. جلب البيانات (الشركات، السيرفرات، روابط التمويه)
if ($action === 'servers') {
    $token = $_SERVER['HTTP_AUTHORIZATION'] ?? '';
    $token = str_replace('Bearer ', '', $token);
    
    // تحقق بسيط من التوكن
    $stmt = $pdo->prepare("SELECT user_id FROM sessions WHERE token = ? AND expires_at > datetime('now')");
    $stmt->execute([$token]);
    if (!$stmt->fetch()) {
        echo json_encode(['success' => false, 'message' => 'غير مصرح أو انتهت الجلسة']);
        exit;
    }

    $companies = $pdo->query("SELECT id, name, name_ar FROM companies WHERE is_active = 1")->fetchAll(PDO::FETCH_ASSOC);
    $servers = $pdo->query("SELECT id, company_id, display_name, host, port, sni_hostname, payload FROM servers")->fetchAll(PDO::FETCH_ASSOC);
    
    // تجميع روابط التمويه حسب الشركة
    $spoofStmt = $pdo->query("SELECT company_id, url, description FROM spoof_urls WHERE is_active = 1");
    $spoofUrlsRaw = $spoofStmt->fetchAll(PDO::FETCH_ASSOC);
    $spoofUrls = [];
    foreach ($spoofUrlsRaw as $row) {
        $spoofUrls[$row['company_id']][] = ['url' => $row['url'], 'description' => $row['description']];
    }

    echo json_encode([
        'success' => true,
        'companies' => $companies,
        'servers' => $servers,
        'spoof_urls' => $spoofUrls
    ]);
    exit;
}

echo json_encode(['success' => false, 'message' => 'إجراء غير معروف']);
?>
```

#### **الملف الثالث: `index.php`** (لوحة تحكم بسيطة للتأكد من العمل)
*هذه صفحة ويب بسيطة لتسجيل دخول الأدمن والتأكد من أن كل شيء يعمل.*

        header("Location: index.php");
        exit;
    } else {
        $error = "بيانات الدخول غير صحيحة";

}
?>

### 🚀 **الخطوة 3: التشغيل والاختبار**

1. في Replit، اضغط على زر **Run** الأخضر في الأعلى.
2. سيفتح لك نافذة صغيرة (Webview). انسخ الرابط من شريط العنوان العلوي (سيكون مثل: `https://your-project.your-username.replit.dev`).
3. **اختبار لوحة التحكم:** ألصق الرابط في متصفحك. يجب أن تظهر شاشة تسجيل دخول. جرب: `admin` / `password`.
4. **اختبار الـ API (الأهم للتطبيق):** أضف `/api.php?action=servers` إلى نهاية الرابط. 
   *مثال:* `https://your-project...replit.dev/api.php?action=servers`
   *(ملاحظة: سيعطيك خطأ "غير مصرح" لأنك لم ترسل Token، وهذا طبيعي ويثبت أن الكود يعمل ويحمي نفسه).*
